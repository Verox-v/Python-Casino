Python Casino

A command-line casino game built with Python. Players can choose between two games and use a shared balance.

Games

Python Slots

Spin three random symbols

Win money by matching all three symbols

Different symbols have different payout multipliers

Python Roulette

Bet on green, black, or red

Spin a random color

Win based on the selected color

Features

Two playable casino games

Shared balance between games

Custom betting system

Input validation

Different payout multipliers

Option to return to the main menu or exit the program

Technologies

Python 3

Random module

How to Run

Make sure Python 3 is installed.

Clone or download this repository.

Open the project folder in a terminal.

Run:

python main.py

Note

This is a beginner Python project created for learning and practice. The balance is stored in memory and resets to $50 when the program is restarted.
